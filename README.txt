Composer Card Quest
Ver.1.8.0

Music Quiz Trainerとは別アプリとして構築した、音楽クイズ＋カード収集ゲームです。

【基本ループ】
1. クイズに挑戦
2. 正解してMusic Point（MP）を獲得
3. MPで作曲家ガチャ
4. 作曲家カードを収集
5. 関連クイズでカード経験値（CXP）を獲得
6. Lv.10でEVOLVEDへ進化
7. カード図鑑のコンプリートを目指す

【MP】
・正解：10 MP
・上級正解：さらに+5 MP
・5問連続正解：+20 MP
・10問連続正解：+20 MP
・10問全問正解：+50 MP
・進化カードが関連する問題へ正解：進化カード1枚につき+2 MP

【ガチャ】
・カード総数：150枚
・N 60枚 / R 45枚 / SR 30枚 / SSR 15枚
・1回：100 MP
・10回：900 MP
・排出率：N 60% / R 28% / SR 10% / SSR 2%
・30回以内にSR以上保証
・100回以内にSSR保証

【重複】
・N：音符のかけら1個 / +10 CXP
・R：3個 / +15 CXP
・SR：10個 / +25 CXP
・SSR：30個 / +40 CXP
・音符のかけら100個で好きな未所持カード1枚と交換可能

【カード育成】
・Lv.1〜10
・関連クイズ正解で+10 CXP
・Lv.10（550 CXP）でEVOLVED
・進化後は関連クイズ正解時に追加MP

【カード図鑑】
・150枚を収録
・未所持は「？？？」表示
・N / R / SR / SSR / 所持のみで絞り込み可能
・カードLv、CXP、進化状態を表示

【保存】
Music Quiz Trainerとは別のlocalStorageキーを使用します。
そのため、既存アプリのMP・カード・学習記録とは混ざりません。

GitHub Pagesで使用する場合は index.html をリポジトリ直下に置いてください。

Ver.1.8.0

【演奏会モード】
・所持カードから3〜4枚を選択して演奏会を開催
・カード内容から自動でシナジーを判定
・演奏会名を自動生成
・統一感、芸術性、完成度、多様性、話題性を採点
・総合評価 C / B / A / S / SS / SSS
・観客数、主催者名声、MP報酬を獲得
・開催回数、最高評価、カード使用回数をlocalStorageに保存

【総合評価式】
総合点 = 統一感×0.35 + 芸術性×0.15 + 完成度×0.20 + 多様性×0.05 + 話題性×0.10 + シナジーPt÷4（最大15点）

【主なシナジー】
作曲家特集、作曲家個展、オール○○、時代を聴く、音楽史をめぐる旅、四つの輝き、熟成された響き、究極のプログラム、バッハ声楽の世界、モーツァルト・ガラ、ベートーヴェン交響世界、三つのレクイエム、フランス音楽祭、20世紀音楽展、日本合唱系、多田武彦系、詩人系、自然・ジャンル系。
