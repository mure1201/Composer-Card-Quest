Composer Card Quest
Ver.1.5.0

Music Quiz Trainerとは別アプリとして構築した、音楽クイズ＋カード収集ゲームです。

【基本ループ】
1. クイズに挑戦
2. 正解してMusic Point（MP）を獲得
3. MPで作曲家ガチャ
4. 作曲家カードを収集
5. 関連クイズでカード経験値（CXP）を獲得
6. Lv.10でEVOLVEDへ進化
7. カード図鑑のコンプリートを目指す

【MP】
・正解：10 MP
・上級正解：さらに+5 MP
・5問連続正解：+20 MP
・10問連続正解：+20 MP
・10問全問正解：+50 MP
・進化カードが関連する問題へ正解：進化カード1枚につき+2 MP

【ガチャ】
・カード総数：150枚
・N 60枚 / R 45枚 / SR 30枚 / SSR 15枚
・1回：100 MP
・10回：900 MP
・排出率：N 60% / R 28% / SR 10% / SSR 2%
・30回以内にSR以上保証
・100回以内にSSR保証

【重複】
・N：音符のかけら1個 / +10 CXP
・R：3個 / +15 CXP
・SR：10個 / +25 CXP
・SSR：30個 / +40 CXP
・音符のかけら100個で好きな未所持カード1枚と交換可能

【カード育成】
・Lv.1〜10
・関連クイズ正解で+10 CXP
・Lv.10（550 CXP）でEVOLVED
・進化後は関連クイズ正解時に追加MP

【カード図鑑】
・150枚を収録
・未所持は「？？？」表示
・N / R / SR / SSR / 所持のみで絞り込み可能
・カードLv、CXP、進化状態を表示

【保存】
Music Quiz Trainerとは別のlocalStorageキーを使用します。
そのため、既存アプリのMP・カード・学習記録とは混ざりません。

GitHub Pagesで使用する場合は index.html をリポジトリ直下に置いてください。

Ver.1.5.0

【カード演出】
・ガチャ結果を段階的に表示するカード出現演出を追加
・R / SR / SSR に応じた発光・出現アニメーションを追加
・ガチャ画面に演出ステージ（召喚オーブ表示）を追加
・R / SR / SSR カードにレア度バースト表示を追加
・EVOLVEDカードに継続発光・バッジ脈動演出を追加
・カード詳細にレア度別の背景演出とシャイン演出を追加

【ガチャ演出仕様】
・ガチャ実行後、召喚ステージを表示
・結果カードは1枚ずつ時間差で表示
・最高レア度に応じて演出メッセージが変化
・演出中は結果一覧を順次解放
・演出終了後に通常操作へ戻る

画像ファイルは引き続き使用せず、HTML/CSS/SVGのみで演出を構成しています。
