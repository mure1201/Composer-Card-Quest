Composer Card Quest
Ver.1.17.0

Music Quiz Trainerとは別アプリとして構築した、音楽クイズ＋カード収集ゲームです。

【基本ループ】
1. クイズに挑戦
2. 正解してMusic Point（MP）を獲得
3. MPで作曲家ガチャ
4. 作曲家カードを収集
5. 関連クイズでカード経験値（CXP）を獲得
6. Lv.10でEVOLVEDへ進化
7. カード図鑑のコンプリートを目指す

【MP】
・正解：10 MP
・上級正解：さらに+5 MP
・5問連続正解：+20 MP
・10問連続正解：+20 MP
・10問全問正解：+50 MP
・進化カードが関連する問題へ正解：進化カード1枚につき+2 MP

【ガチャ】
・カード総数：150枚
・N 60枚 / R 45枚 / SR 30枚 / SSR 15枚
・1回：100 MP
・10回：900 MP
・排出率：N 60% / R 28% / SR 10% / SSR 2%
・30回以内にSR以上保証
・100回以内にSSR保証

【重複】
・N：音符のかけら1個 / +10 CXP
・R：3個 / +15 CXP
・SR：10個 / +25 CXP
・SSR：30個 / +40 CXP
・音符のかけら100個で好きな未所持カード1枚と交換可能

【カード育成】
・Lv.1〜10
・関連クイズ正解で+10 CXP
・Lv.10（550 CXP）でEVOLVED
・進化後は関連クイズ正解時に追加MP

【カード図鑑】
・150枚を収録
・未所持は「？？？」表示
・N / R / SR / SSR / 所持のみで絞り込み可能
・カードLv、CXP、進化状態を表示

【保存】
Music Quiz Trainerとは別のlocalStorageキーを使用します。
そのため、既存アプリのMP・カード・学習記録とは混ざりません。

GitHub Pagesで使用する場合は index.html をリポジトリ直下に置いてください。

Ver.1.17.0

【シナジー発見報酬】
シナジーを初めて発見した際にMPと名声を獲得します。

発見MP = 30 + シナジーPt × 2
発見名声 = 1 + floor(シナジーPt ÷ 20)

例：
・8 Ptシナジー → 46 MP / 1名声
・20 Ptシナジー → 70 MP / 2名声
・30 Ptシナジー → 90 MP / 2名声
・45 Ptシナジー → 120 MP / 3名声
・48 Ptシナジー → 126 MP / 3名声

【Ver.1.9.0からの引き継ぎ】
Ver.1.9.0ですでに発見済みのシナジーには reward 状態がありません。
そのためVer.1.17.0以降にそのシナジーをもう一度発動した際、
1回だけ発見報酬を受け取れます。

Ver.1.17.0

【セーブデータ バックアップ / 復元】
ホーム画面に「セーブデータ」を追加しました。

■ バックアップ
「バックアップを書き出す」を押すと、
Composer-Card-Quest-save-YYYYMMDD-HHMMSS.json
というJSONファイルを保存します。

対象：
・カード所持状況
・MP
・カード育成 / EVOLVED
・名声
・ホール
・設備強化
・シナジー履歴 / 発見報酬
・演奏会履歴
・クイズ成績
・その他、localStorage内の ccq_ で始まる保存データ

■ 復元
「バックアップから復元」を押し、
過去に保存したJSONファイルを選択すると復元できます。

復元前に以下を確認します：
・Composer Card Quest用のバックアップ形式か
・対応する形式バージョンか
・ccq_game_v1 が含まれているか
・ccq_ 以外の不正な保存キーがないか

復元を実行すると、現在の ccq_ で始まる保存データを削除して、
バックアップ内のデータで置き換えた後、画面を再読み込みします。

【注意】
ブラウザのサイトデータ / localStorageを消去する前に、
バックアップJSONを端末やクラウドストレージへ保存してください。

・古い世代から自動的に削除
・「セーブデータ」画面で日時・MP・名声・演奏会履歴件数を確認可能
・各世代からワンタップで復元可能
・個別削除 / 全削除に対応
・「今すぐ自動バックアップ」で手動スナップショット作成可能

【復元保護】
JSONバックアップから復元する直前にも、自動バックアップを1世代作成します。
自動バックアップから別の世代を復元する直前にも、現在状態を1世代保存します。

【重要】
自動バックアップはlocalStorageに保存されるため、
Safari等で「Webサイトデータ」を削除すると通常セーブと一緒に消えます。
サイトデータ削除・機種変更・別ブラウザ利用に備える場合は、
従来の「バックアップを書き出す」でJSONファイルを端末外へ保存してください。

外部JSONバックアップには自動バックアップ世代そのものは含めません。
